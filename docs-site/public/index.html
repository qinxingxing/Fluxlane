Fluxlane API 文档

通过统一的 OpenAI 兼容接口调用平台已开放的 AI 模型。包含用户接入说明与调用指南。

5 分钟快速接入联系销售打开控制台

平台概览

Fluxlane 为合法授权的上游模型服务提供统一入口、身份认证、额度计量和调用日志。

统一接口

OpenAI 兼容格式接入多种模型。

密钥隔离

独立配额、模型限制与 IP 白名单。

用量可视

查看 Token、扣费和请求日志。

只允许使用平台已授权开放的模型。禁止违法、侵权、绕过上游限制或其他滥用行为。

快速开始

  1. 访问 控制台并登录。
  2. 进入「API 密钥（令牌）」页，创建并立即保存 Key。
  3. 在「模型广场」确认可用模型名称和价格。
  4. 发送请求：
curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"model":"模型名称","messages":[{"role":"user","content":"你好"}]}'

API 密钥在列表中默认掩码显示，可随时在控制台查看或复制完整 Key。疑似泄露时立即删除旧密钥并创建新密钥。

API 调用

Base URL 为 https://run.fluxlane.ai。按下面的厂商和路径选择请求体。对话、识图、工具往往在同一条路径上，用不同字段区分；生图是另一条路径。

POST /v1/chat/completions

对话、识图和函数工具走这条路径。Claude 也可以用 OpenAI SDK 走同一路径，平台会转成 Claude Messages，见 Anthropic。

{
  "model": "模型名称",
  "messages": [
    {"role": "system", "content": "你是一名简洁的中文助手。"},
    {"role": "user", "content": "解释向量数据库。"}
  ],
  "temperature": 0.7,
  "stream": false
}

适用模型

上表里「对话」列为这条路径的模型。四个只用 Responses 的模型不要调用本路径，也不要传 messages。

流式输出

将 stream 设为 true 后，响应为 SSE 分片（text/event-stream），以 data: [DONE] 结尾。请求带 "stream_options": {"include_usage": true} 时，最后一个 chunk 会包含 usage。

curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "模型名称",
  "messages": [{"role": "user", "content": "用一句话介绍流式输出。"}],
  "stream": true,
  "stream_options": {"include_usage": true}
}'

图像

这里是识图，不是生图。content 写成数组，用 image_url 传入图片。下面示例里的 base64 是一张 1×1 的 PNG。模型是否接受图片，见对应厂商小节，并以模型广场为准。

curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "模型名称",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "描述这张图片。"},
      {"type": "image_url", "image_url": {"url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="}}
    ]
  }]
}'

工具

工具不是单独接口。请求携带 tools 和 tool_choice。模型在 message.tool_calls 中返回调用；把工具结果以 role 为 tool、并带上对应 tool_call_id 的消息追加到 messages 后再次请求。示例中的 call_abc123 需换成上一次响应返回的 id。

第一次请求：

curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "模型名称",
  "messages": [{"role": "user", "content": "北京今天天气如何？"}],
  "tools": [{
    "type": "function",
    "function": {
      "name": "get_weather",
      "description": "查询指定城市的天气",
      "parameters": {
        "type": "object",
        "properties": {"city": {"type": "string"}},
        "required": ["city"]
      }
    }
  }],
  "tool_choice": "auto"
}'

响应中的 message.tool_calls 形如：

{
  "role": "assistant",
  "tool_calls": [{
    "id": "call_abc123",
    "type": "function",
    "function": {
      "name": "get_weather",
      "arguments": "{\"city\":\"北京\"}"
    }
  }]
}

回传工具结果：

gpt-6-luna 和 gpt-6-sol 在本路径上使用工具时，须带 "reasoning_effort": "none"，输出长度用 max_completion_tokens。回传方式与上面相同。gpt-6-astra 不能在本路径使用工具，改走 Responses。

curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "gpt-6-luna",
  "max_completion_tokens": 1024,
  "reasoning_effort": "none",
  "messages": [{"role": "user", "content": "北京今天天气如何？"}],
  "tools": [{
    "type": "function",
    "function": {
      "name": "get_weather",
      "description": "查询指定城市的天气",
      "parameters": {
        "type": "object",
        "properties": {"city": {"type": "string"}},
        "required": ["city"]
      }
    }
  }],
  "tool_choice": "auto"
}'
GPT-6 在本路径上默认开启推理，此时携带 tools 会被拒绝。需要工具时按上表选择路径，或为 gpt-6-luna、gpt-6-sol 设置 reasoning_effort 为 none。

输出长度

GPT 新系列使用 max_completion_tokens。三个 GPT-6 模型只换 model。

curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "gpt-6-sol",
  "max_completion_tokens": 1024,
  "messages": [{"role": "user", "content": "你好"}]
}'
请求里如果仍带 max_tokens，请求会被拒绝，请改用 max_completion_tokens。

POST /v1/responses

四个只用 Responses 的模型，以及 gpt-6-astra、gpt-6-sol 的工具调用，使用本路径。内容放在 input，不要传 messages。

curl https://run.fluxlane.ai/v1/responses \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "gpt-5.1-codex-mini",
  "input": "你好"
}'

图像

官方 Responses 的识图字段是 input_image，image_url 为字符串。不要把 Chat Completions 里的 image_url 对象原样放进本路径。GPT 对话模型在本平台的识图请走 Chat Completions。

工具

gpt-6-astra 和 gpt-6-sol 的工具调用放在本路径：工具声明用 tools，输出长度用 max_output_tokens。模型在 output 里返回 type 为 function_call 的条目。官方生图工具 image_generation 依赖 gpt-image-* 模型，平台尚未接入。

curl https://run.fluxlane.ai/v1/responses \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "gpt-6-sol",
  "max_output_tokens": 1024,
  "input": "北京今天天气如何？",
  "tools": [{
    "type": "function",
    "name": "get_weather",
    "description": "查询指定城市的天气",
    "parameters": {
      "type": "object",
      "properties": {"city": {"type": "string"}},
      "required": ["city"]
    }
  }]
}'

响应 output 中的工具调用形如：

{
  "type": "function_call",
  "call_id": "call_abc123",
  "name": "get_weather",
  "arguments": "{\"city\":\"北京\"}"
}

把工具结果以 function_call_output 追加到 input 后再次请求。示例中的 call_abc123 需换成上一次响应返回的 call_id：

curl https://run.fluxlane.ai/v1/responses \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "gpt-6-sol",
  "max_output_tokens": 1024,
  "input": [
    {"role": "user", "content": "北京今天天气如何？"},
    {"type": "function_call", "call_id": "call_abc123", "name": "get_weather", "arguments": "{\"city\":\"北京\"}"},
    {"type": "function_call_output", "call_id": "call_abc123", "output": "晴，26°C"}
  ],
  "tools": [{
    "type": "function",
    "name": "get_weather",
    "description": "查询指定城市的天气",
    "parameters": {
      "type": "object",
      "properties": {"city": {"type": "string"}},
      "required": ["city"]
    }
  }]
}'
gpt-6-luna 的 Responses 请求会由平台转换为 Chat Completions 上游：须带 "reasoning": {"effort": "none"} 才能使用工具，且返回的 arguments 是双重编码的 JSON 字符串。luna 需要工具时用上面的 Chat Completions 示例。

POST /v1/completions

旧版文本补全。图像和工具都不在这条路径上。对话请用 /v1/chat/completions 或 /v1/responses。

POST /v1/images/generations

官方生图使用 gpt-image-* 图像模型，例如 gpt-image-2.5-sunburst。GPT 对话模型在 /v1/chat/completions 上只返回文字。平台尚未接入 image 模型，本路径当前不可用。

Anthropic

claude-haiku-4-5-20251001 使用 Anthropic Messages。下面两种调用都可以。模型名以模型广场为准。

POST /v1/messages

必须带 max_tokens 和 messages。不要用 max_completion_tokens 或 input。

新一代 Claude Haiku（Haiku 5.5）官方已废弃采样参数：请求中 temperature 只能为 1、top_p 只能为 0.99，传 top_k 或同时传 temperature 与 top_p 会返回 400；应省略这些参数，改用提示词引导模型行为。本页示例使用的 claude-haiku-4-5-20251001 仍接受这些参数。参考：Anthropic Haiku 5.5 迁移指南。

认证任选其一：

Chat Completions

也可以 POST /v1/chat/completions。平台会转成 Claude Messages。未传 max_tokens 时，平台按默认值补上。识图和工具仍建议用上面的 Messages 字段；若走 Chat Completions，图片字段是 OpenAI 的 image_url。

curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "claude-haiku-4-5-20251001",
  "messages": [{"role": "user", "content": "你好"}]
}'

不支持

  • POST /v1/responses。请求分到 Anthropic 渠道后返回 not implemented。
  • POST /v1/completions
  • POST /v1/images/generations

GLM

POST /v1/chat/completions

智谱对话补全。文本、识图和工具都在这一条路径上。请求体与 OpenAI Chat Completions 相同，把 model 换成 GLM 模型名。

适用模型

glm-5.3-flash 支持识图和工具。glm-5.3 支持文本和工具，不接受图片。

图像

识图只用于视觉模型。content 写成数组，用 image_url 传入 URL 或 base64 data URL。向 glm-5.3 发送图片会被上游拒绝。

工具

使用 tools。结果以 role 为 tool 的消息回传，格式见 OpenAI Chat Completions · 工具。

不支持

  • POST /v1/responses
  • POST /v1/completions
  • POST /v1/messages

Kimi

POST /v1/chat/completions

Kimi 官方对话补全。文本、识图和工具都在这一条路径上。模型包括 kimi-k3、kimi-k2.5、kimi-k2.6、kimi-k2.7-code、kimi-k2.7-code-highspeed。文本请求体与 OpenAI Chat Completions 相同。

图像

识图时 message.content 必须是对象数组，不要把数组序列化成字符串。图片使用 base64 data URL，或 Moonshot 文件 ID（ms://）。Kimi 官方不接受公网图片 URL。SVG 不能作为图片输入。

curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "kimi-k3",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "描述这张图片。"},
      {"type": "image_url", "image_url": {"url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="}}
    ]
  }]
}'

工具

使用 tools。本地执行后，原样回传 assistant 消息，并用 role 为 tool、tool_call_id 对应的消息逐条回传结果。格式见 OpenAI Chat Completions · 工具。

不支持

  • POST /v1/responses
  • POST /v1/completions
  • POST /v1/messages
  • POST /v1/images/generations

DeepSeek

DeepSeek 官方当前看图模型是 deepseek-flash（V4.1-Flash）。在本平台的模型名是 deepseek-v4.1-flash。deepseek-v4-flash-0731 同样按图片处理输入。Chat Completions 和 Responses 都能传图，字段不同。参考：DeepSeek 图像理解、DeepSeek Responses API。

模型识图
deepseek-v4.1-flash支持。Chat Completions 与 Responses 都按图片处理，并按图片 token 计费
deepseek-v4-flash-0731支持。字段与 deepseek-v4.1-flash 相同
deepseek-v4-proDeepSeek 不把图片交给模型，回复中看不到图片内容
deepseek-v4-pro-0813DeepSeek 把图片替换成占位文本
deepseek-v4-flash不是官方当前看图模型。识图改用上面两个模型

官方旧名 deepseek-v4-flash-vision-exp 已退役，请求由最新 Flash 承接。请使用 deepseek-v4.1-flash。

POST /v1/chat/completions

适用模型

文本对话可用已上架的 DeepSeek 模型。识图使用 deepseek-v4.1-flash 或 deepseek-v4-flash-0731。

图像

content 写成数组。image_url.url 为 http(s) URL（最长 8192 字符）或 base64 data URL（data:image/jpeg;base64,...）。格式由文件内容判断：JPEG、PNG、GIF、WebP。detail 可选 low、high、original、auto。low 在推理前缩到 512×512，其余保留原图。

官方另支持 file_id（形如 file-api-...），与 image_url 互斥；使用 file_id 时忽略 detail。下面示例使用 data URL。

curl https://run.fluxlane.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "deepseek-v4.1-flash",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "这张图片里有什么？"},
      {"type": "image_url", "image_url": {"url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==", "detail": "low"}}
    ]
  }]
}'

官方限制：内联单张 32 MiB，file_id 单张 64 MiB，请求体 48 MiB，单请求最多 600 张，单边最长 8192 像素（15 张及以上降为 4096）。图片出现在 system 或 assistant 消息中时，DeepSeek 返回 400。

工具

使用 tools。结果以 role 为 tool 的消息回传，格式见 OpenAI Chat Completions · 工具，model 改为 DeepSeek 模型名。

POST /v1/responses

内容放在 input。识图模型同样是 deepseek-v4.1-flash 与 deepseek-v4-flash-0731。不要把 Chat Completions 的 image_url 对象放进本路径。

图像

使用 input_image。image_url 在这里是字符串，不是对象；也可以改传 file_id，二者只能有一个。detail 的取值与对话补全相同，传 file_id 时被忽略。

图片可以出现在 user / developer 消息，以及 function_call_output / custom_tool_call_output 的 output 中。system 或 assistant 消息中的图片，DeepSeek 返回 400。大小限制与对话补全相同。

curl https://run.fluxlane.ai/v1/responses \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "deepseek-v4.1-flash",
  "input": [{
    "role": "user",
    "content": [
      {"type": "input_text", "text": "这张图片里有什么？"},
      {"type": "input_image", "image_url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==", "detail": "low"}
    ]
  }]
}'

工具

工具不是单独接口。声明 {"type": "function", ...}，结果用 function_call_output 回传。字段形状见 Responses 工具示例，model 改为 deepseek-v4.1-flash。DeepSeek 忽略 web_search、file_search 等内置工具。工具返回的图片放在 output 的 input_image 里。

不支持

  • POST /v1/completions
  • POST /v1/messages
  • POST /v1/images/generations。DeepSeek 没有生图接口

SDK 示例

Python（OpenAI SDK）

from openai import OpenAI
client = OpenAI(
    api_key="sk-你的令牌",

)

Python（Anthropic SDK）

使用 Anthropic 官方 Python SDK。base_url 填写 https://run.fluxlane.ai，由 SDK 请求 /v1/messages。

import anthropic
client = anthropic.Anthropic(
    base_url="https://run.fluxlane.ai",
    api_key="sk-你的令牌"
)
result = client.messages.create(
    model="模型名称",
    max_tokens=1024,
    messages=[{"role": "user", "content": "你好"}]
)
print(result.content[0].text)

用量与计费

请求按模型价格、输入/输出 Token、缓存命中及分组倍率扣减额度。「日志」中可查看模型、Token、响应时间与扣费。

  • 调用前在 模型价格页 确认价格与可用性。
  • 合理设置 max_tokens。
  • 生产密钥设置独立配额并监控异常用量。

常见错误

状态原因处理
401API 密钥错误、过期或禁用检查请求头，重新生成密钥
403模型/分组/IP 无权限，或额度不足检查密钥限制与账户余额
429限速/限流降低并发，指数退避
400模型名或参数错误对照模型广场与接口格式
500/502上游异常稍后重试；管理员检查渠道
503无可用渠道或上游服务不可用稍后重试；确认模型可用性或联系管理员
666网关收到上游非 200 响应，错误码为 bad_response_status_code。常见于模型不支持该请求，例如向 glm-5.3 发送图片，或在 /v1/chat/completions 向 gpt-6* 发送工具调用而未关闭推理对照对应厂商的调用说明检查请求。报障时附上响应头 X-Oneapi-Request-Id
超时生成较慢或网络中断启用流式输出，提高客户端超时
